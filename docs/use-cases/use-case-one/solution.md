## Begin Collaborating with a Workshop

Use a workshop to fully define use case one opportunity.  Integration projects benefit more from technical collaboration such as architecture white-boarding than depth Design Thinking, but a well curated set of workshop activities will typically provide the needed understanding of customer objectives over integration and general IT practices.  Gaining buy-in for any type of change can be difficult when working with integration stakeholders.  Many times the drive for change is happening from outside of their immediate organization.  It is important to bring all factions into alignment. 

This activity typically will run 2-6 hours with flexible agendas available.  Combine with materials from the Agile Integration Workshop and / or an Architecture White-Boarding exercise.  The workshop aligns the client and IBM teams on the proposed applications and benefits of the pattern capabilities:

- Rapidly *use case one
- More use case one
- Even more use case one

![api-co-creation](images/api-co-creation.png)

As with other workshops, the use case one  workshop agenda may be customized to meet each customer where they are.  

**Audience:** Enterprise Architects / Integration Architects / Integration Specialists / CIO / API Developers & Managers<br>
**Purpose:** Inspire, inform and align towards PoC<br>
**Topics:** API-Led Integration opportunities the focus is on APIC, API Gateway and ACE (IIB)<br>
**Duration:** 2-6 Hours (Add 2+ hours if the Architecture White-Boarding exercise is being included)<br>
**Facilitators:** 2-3 (Architect, SME, Designer)<br>
**Output:** Playback, well-formed opportunity with next steps leaning into the PoC<br>

**Agenda Topics:**

- Inspire and Inform: Use case one
- Introduce the Use case one
- (Optional) Demo
- Discover the existing Use case one landscape (As-Is)
- Brainstorm and framing of the opportunity
- High-Level architecture white-boarding
- PoC development
- Next steps and wrap-Up
